# Security policy for Reponomics plugins

This policy covers the plugins in this repository, their scripts and hooks, and the release workflow and verification process.

## Supported versions

Security fixes are made on the `main` branch and published in the next release of each affected plugin. Only the latest release of each plugin is supported; earlier releases are not patched.

## Report a vulnerability

Please don't open a public issue, discussion, or pull request with vulnerability details. Report privately by either route:

- GitHub private vulnerability reporting: [open a report](https://github.com/reponomics/plugins/security/advisories/new) from the repository's Security tab.
- Email: `security@reponomics.org`.

Include the affected plugin and version, instructions for reproducing the vulnerability, and the impact you believe it could have.
