# Badge Progress 0.3.0-beta.1

This initial public beta adds progress displays to Claude Code while you work on an OpenSSF application with Badge Buddy.

- View recorded answers, status counts, missing evidence, and unresolved website differences in a pane opened by `/badge-progress`.
- See a progress band while Claude records answers and a short notice summarizing the turn's changes.
- Retain the latest counts per project between sessions, using Badge Buddy command results without additional network requests.

Install alongside Badge Buddy. Counts describe the working assessment, not a badge percentage or confirmation that answers have been saved on the website.
