# Badge Progress 0.1.0

Badge Progress adds a progress pane and an above-prompt progress band to Claude Code while you work on an OpenSSF Best Practices application with Badge Buddy. This initial release is a mod implemented through function hooks, with no additional skills.

- View answer counts for each started badge section, including status breakdowns, missing justifications or URLs, and differences from the saved website entry.
- See progress while Claude records answers and a short summary at the end of the turn. Reopen the pane with `/badge-progress`.
- Keep the last counts per project directory between sessions. The display refreshes when Claude runs the relevant Badge Buddy commands and makes no network requests of its own.

Install Badge Buddy alongside Badge Progress, then start or resume badge work as usual; no additional setup is required. Counts describe answers recorded in the working assessment, including Unmet and N/A answers. They are not a badge percentage or confirmation that the website entry has been saved. Cached counts remain visible until the next status refresh.
