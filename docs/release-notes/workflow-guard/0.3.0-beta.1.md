# Workflow Guard 0.3.0-beta.1

This initial public beta checks GitHub Actions files that Claude writes or edits and reports newly introduced pinning or token-permission problems.

- Block new external action and reusable-workflow references that lack a full commit SHA, and newly missing or write-enabled top-level token permissions.
- Let Claude correct a blocked edit immediately, or select warning mode to receive findings without blocking.
- Support explicit file comments and a user-managed ignore list for intentional exceptions; composite actions receive pinning checks only.

The guard checks Claude's Write and Edit tools, not shell-based changes. Its line-based checks do not cover every YAML construct or verify that a pinned SHA exists or matches a version label.
