# Release Buddy 0.3.0-beta.1

This initial public beta helps small projects choose a manageable versioning process and prepare verifiable GitHub releases.

- Choose version policies, release units, changelogs, and suitable automation without requiring signing setup.
- Prepare signed source tags and immutable GitHub releases, with maintainer and consumer guides covering identity checks and interrupted draft recovery.
- Extend an existing primary build artifact with provenance when needed, or include scoped OSV evidence when dependency scanning is selected.

Integrity setup supports public GitHub repositories. It does not provision registry publishers, publish containers, or deploy services. Signatures, provenance, and scan reports establish specific evidence; they do not certify security or guarantee a badge.
