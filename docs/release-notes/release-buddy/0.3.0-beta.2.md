# Release Buddy 0.3.0-beta.2

Corrects the consumer verification template and supporting guidance for signed annotated release tags.

- Compare the Git digest in GitHub's verified release attestation with the signed **tag object ID**, rather than the peeled source commit ID.
- Keep the tag object and source commit separate: the verified tag binds the release name to its source commit, while optional build-provenance verification still checks that commit.

If you generated a verification guide with beta.1, update its immutable-release comparison accordingly. This correction does not require replacing existing signed tags or release assets.
