# Starter Buddy 0.3.0-beta.1

This initial public beta helps maintainers prepare useful community files for GitHub repositories.

- Inspect existing files and inherited defaults before adding a README, contribution guide, issue forms, pull request template, or chosen policies.
- Adapt bundled templates to the project's actual contacts, contribution preferences, licensing decisions, and maintenance commitments.
- Prepare local changes or, when requested, a pull request, with checks for file locations, form structure, links, contacts, and unresolved placeholders.

Security and conduct policies are optional choices that need real ownership. Community Standards checks are setup signals, not certification of project quality or security.
