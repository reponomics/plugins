# Starter Buddy 0.3.0-beta.2

Adjusts the bundled issue forms so new issues arrive pre-labelled and the security notice appears only where it is relevant.

- The bug, suggestion, and documentation forms now set a title prefix (`[BUG]: `, `[FEAT]: `, `[DOCS]: `) and one of GitHub's default labels (`bug`, `enhancement`, `documentation`). Starter Buddy checks that each label exists in the target repository and removes the entry or asks before creating the label.
- The instruction not to publish vulnerability details, with its link to the private reporting route, now appears only in the bug-report forms and the general report template. The suggestion and documentation forms no longer carry it.
- The chooser configuration no longer needs a security contact link: when a repository has a security policy, GitHub's issue chooser already links to it.

Forms generated with beta.1 keep working. To adopt the new defaults, add the `title` and `labels` keys to existing forms and confirm the labels exist.
