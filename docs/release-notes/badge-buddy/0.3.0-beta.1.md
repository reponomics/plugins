# Badge Buddy 0.3.0-beta.1

This initial public beta helps maintainers understand OpenSSF criteria, prepare badge applications, and improve their projects.

- Work through Best Practices Passing, Silver and Gold, plus Security Baseline levels 1–3, with saved assessments, local review boards, and reviewed transfer options for the badge website.
- Investigate published Scorecard findings and use independent skills for GitHub Actions maintenance, test-coverage baselines, and static analysis.
- Keep control of application answers and website submission. Badge Buddy is an independent assistant; it does not award badges or certify security.

The command-line helpers require Python 3.11 or newer. Synchronized assessments currently require a GitHub repository.
