# OpenSSF Best Practices skill

This skill helps Claude explain the badge criteria, prepare application answers, and implement improvements to a project. It covers Passing, Silver, Gold, and Security Baseline levels 1–3. See the [Badge Buddy README](../../README.md) for installation and use.

A second agent reviews Claude's contribution before Claude presents drafted answers or revisions. The subject is Claude's work: its writing, criterion interpretation, and respect for the user's instructions and account. The form is examined only to assess that contribution, whether one answer or a whole draft. The reviewer does not approve the user's application or investigate their honesty. The user can skip the review or stop at any time.
