# Look up a BadgeApp example

When the user asks how BadgeApp answered a criterion, or a real example would clarify the expected wording, retrieve that criterion's `_status` and `_justification` fields from the bundled [project.json](../../../assets/examples/badgeapp/project.json). Baseline fields use display IDs, such as `OSPS-GV-02.01_status`.

Read only the selected answer. It describes BadgeApp's practices at the time of the snapshot, and its links or descriptions may be dated. Use it to illustrate wording; the selected criterion determines the requirements, and the current project's practices determine its answer. Keep the example data separate from the user's assessment.
